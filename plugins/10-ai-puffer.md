## What it does
AI suite: MCP server (ChatGPT/Claude manage site), chatbot, content writer, automations,
AI forms, images, voice.

## Knowledge base
- Chunk content, retrieve passages per question (RAG)
- Vector store: LOCAL WP DB, OpenAI vector stores, Google File Search, Pinecone, Qdrant, Chroma
- Free sources: posts, pages, products, CPTs, Q&A pairs, pasted text (incl. page builders)
- Paid: file/PDF uploads, RSS/URL/Google Sheets sources
- Auto-sync: NOT general; only via automations adding NEW posts by category. Users ask bulk refresh.
- Citations: no. Answers NOT restricted to KB (confidence threshold, can use general knowledge).

## Pricing
Free + paid (Freemius). AI Puffer Cloud credits (25 free/month) or BYO key.

## Data
Local DB for logs/KB. Cloud mode relays via AI Puffer. MCP via hosted bridge mcp.aipuffer.org.

## Weaknesses (for our goal)
- No real auto-sync of edited content
- PDFs paid
- No citations, can go off-content
- Huge suite, KB is side feature
