## What it does
Connector to hosted SaaS chatbot. "Connect with WebChatAgent" button, no API key needed.
AI answers from site content + docs, captures leads, books appointments, staff can take over
via live chat. Settings managed in WebChatAgent dashboard (read-only in WP).

## Features
RAG; crawler handles JS-rendered pages; lead capture + qualification; appointment booking;
Form Builder; Action Bar (links, WhatsApp, Calendly); proactive triggers (time, scroll,
exit intent, inactivity); shared inbox + live chat takeover and return to AI; multilingual;
voice input; file upload; streaming; analytics, tickets, feedback, knowledge testing.
Embed: floating widget, `[webchatagent_inline]` shortcode, Gutenberg block, per-embed Chatbot ID.
Dev hook: `webchatagent_context_data` filter passes session context.

## AI / LLM
OpenAI, Gemini, Grok, Mistral (hosted, no own key).

## Knowledge sources
Website pages (auto on connect), PDF, Word, spreadsheets, Notion, Confluence.

WooCommerce + API connectors (product details, order status w/ identity verification). WhatsApp, Calendly.
