# WPBot – AI ChatBot (QuantumCloud)

- URL: https://wordpress.org/plugins/chatbot/
- Fetched: 2026-10-27
- Version 8.8.8 · since 2018-08 · 5,000+ installs · 4.7★ (124 reviews, 7 one-star)
- Requires WP 6.2+, PHP 7.4+ · tested WP 7.1.3

## What it does
All-in-one WordPress chatbot: live support, lead gen, conversational forms, booking, FAQ.
Works with or without an LLM (keyword/button menu mode). Grown into automation suite:
Automator (visual builder), AI Actions, AI Marketing, AI Content Generator.

## Features
Free: keyword responses, FAQ builder, site search, conversational forms, mail us / call back /
feedback, start menu builder, templates, RTL, no-LLM mode.

Pro: multi-LLM, RAG vector DB + embeddings, drag-drop form builder w/ conditional logic,
Google Calendar booking, webhooks (CRM/email), WooCommerce (catalog, in-chat cart, abandoned cart),
onsite retargeting (exit intent, scroll, tab flash), omnichannel (FB, IG, Messenger, WhatsApp,
Telegram), human escalation via Slack/dashboard, voice in/out, white label, cross-site embed,
agency dashboard, chat logs, GDPR settings, daily AI summary email, conversion analytics.

## AI / LLM
OpenAI (fine-tuning, Assistants = Pro Professional/Master), Gemini, Claude (Voyage AI embeddings),
Grok, OpenRouter, Mistral/Groq (Automator), Dialogflow CX. Dialogflow + OpenAI cannot run together.

## Knowledge sources
Pages, posts, CPTs, sitemap links -> vector DB. Uploads: PDF, XML, CSV, JSON. Google Sheets (per review).

## Pricing
No prices on page. Tiers: Free / Pro Professional / Pro Master. Master Lifetime: one-time,
50 sites, white label — pitched to agencies. Multilingual = Master only.

## Integrations
WooCommerce, Zapier, webhooks, FluentCRM, HubSpot, MailChimp, Google Calendar/Sheets, Slack,
Messenger, IG, WhatsApp, Telegram.

## Strengths
- Most mature + biggest install base so far; huge feature set
- Bring-your-own LLM, many providers; works offline of LLM too
- Agency angle: lifetime 50-site license, white label

## Weaknesses
- Feature bloat; complex settings
- Key KB features (RAG, multilingual) paywalled
- Uses WP default mailer (spam risk); caching issues after settings change
- OpenAI credit exhaustion = bot hangs loading
