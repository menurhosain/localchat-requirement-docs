## What it does
Documentation / knowledge base builder (docs layouts, FAQ, wikis, glossary) + MCP server.
NOT primarily a chatbot.

## AI chatbot
PRO add-on. "Instant AI-powered support" from docs. Retrieval method, sync, hosting NOT documented.
AI features BYO key: OpenAI, Anthropic, Gemini, OpenRouter, DeepSeek.
"Instant Answers" (Pro) = browse docs in chat window.

## Other

role-based internal docs, Git sync (Pro), Help Scout migration, WPML.
