# MxChat (mxchat.ai)

- URL: https://wordpress.org/plugins/mxchat-basic/
- Fetched: 2026-10-27
- Version 3.2.27 · 2,000+ installs · 5★ (31 reviews)

## What it does
Chatbot answering from site content via RAG + content generator, lead capture, actions.

## Knowledge base — CLOSEST TO OUR GOAL
- Sources: pages, posts, Woo products, CPTs, PDF, Word, text files, sitemaps, URLs,
  YouTube videos, manual Q&A
- RAG: embeddings, top matches passed to model
- Embeddings: OpenAI, Gemini, Voyage, OpenAI-compatible (Ollama, LM Studio)
- Vector storage: LOCAL in WP database, free, unlimited. Pinecone optional for large KBs.
- Auto-sync on publish/update of posts, pages, products, CPTs (skips unchanged)
- Sources + relevance scores shown in admin transcripts/debug panel — NOT shown to visitor
- All free (unlimited training)

## Free vs paid
Free: multi-provider, unlimited training, content generator, lead capture, web search,
image gen, transcripts, debug panel. Paid add-ons: MCP, Woo, Forms, MxChat Anywhere,
theme customizer, Multi-Bot, image analysis. Prices not on page; reviewer says cheap, no annual fee.

## AI providers
OpenRouter, OpenAI, Claude, Grok, Gemini, DeepSeek, custom/local.

## Data
Chats stored locally. BYO key. Pro license check to mxchat.ai (no visitor data).

## Other
Slack live-agent handoff, trigger phrases, function calling, leads tab, Brave web search,
REST API, role access, RTL.

## Weaknesses
- Visitor doesn't see citations
- Re-index needed on embedding model change
- Feature sprawl (content gen, images) beyond KB
- 20/24 support issues resolved; past caching/CSS/Cloudflare conflicts
